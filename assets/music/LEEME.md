# Música

Pon aquí la canción que quieras con el nombre exacto:

```
cancion.mp3
```

Si el archivo no está, la página no se rompe: suena una melodía suave tipo cajita musical que el propio navegador genera.

Para usar otro nombre o formato, cambia la línea `musica` en `js/config.js`.

Ojo con canciones pesadas: GitHub no acepta archivos de más de 100 MB, y lo ideal es que pese menos de 10 MB para que cargue rápido en el celular.
